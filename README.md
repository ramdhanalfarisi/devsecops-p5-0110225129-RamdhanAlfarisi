# DevSecOps Practice 5 - TaskTracker CLI

## 1. Nama Aplikasi & Fungsi
**TaskTracker CLI** adalah aplikasi manajemen tugas berbasis Command Line Interface (CLI) yang memungkinkan pengguna untuk mencatat, melihat, memperbarui status, dan menghapus daftar tugas harian secara aman.

## 2. Bahasa & Framework
- **Bahasa Pemrograman**: Python 3.12
- **Database**: SQLite3 (Penyimpanan lokal / In-Memory)
- **Testing Framework**: Pytest
